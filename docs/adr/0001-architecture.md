# ADR 0001: Единый движок для CLI и HTTP API

Статус: принято для v0.1.

Контекст: диагностика адресов из HTTP API может использоваться для SSRF; CLI должен работать и без сервера.

Решение: обе точки входа используют `diagnostics.Engine` и `security.Policy`. Сервер создаёт только публичную policy и ограничивает параллельность. CLI может разрешить приватные адреса явным флагом. Подключение закрепляется за проверенным IP.

Последствия: новые проверки добавляются без изменения цикла, но пока нет модели заданий и долгоживущего хранилища. Дальнейшая оркестрация должна сохранять ту же security policy.
