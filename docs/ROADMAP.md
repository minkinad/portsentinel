- [ ] v0.1 hardening: полная классификация ошибок, дополнительная проверка редактирования URL/ошибок, тест DNS rebinding и redirect.
- [ ] v0.2: job orchestration, несколько целей, планировщик, история и сравнение результатов.
- [ ] v0.3: distributed agents, взаимная TLS-аутентификация, gRPC и диагностика из нескольких сетевых точек.
- [ ] v0.4: HTML-отчёты, web dashboard, incident correlation.
- [ ] v0.5: Kubernetes Service/Ingress inspection с ограниченными правами.
